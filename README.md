
# 📈 DataQuant & Signal

**Quantitative Stock Market Analysis & Trading Signal Platform for Vietnam**

DataQuant & Signal is a quantitative analysis platform designed to collect, store, and analyze Vietnamese stock market data across **HOSE, HNX, and UPCOM**.

The system uses market data providers to synchronize historical prices, calculate technical indicators, and generate BUY/SELL signals based on quantitative trading strategies. A **Streamlit dashboard** provides interactive visualizations, signal filtering, and data pipeline monitoring.

## ✨ Features

### 📊 Market Data Infrastructure

- Automated stock symbol synchronization across HOSE, HNX, and UPCOM.
- Daily OHLCV data collection.
- Historical price data storage.
- Data gap detection and repair.
- PostgreSQL database integration.

### 📉 Technical Analysis

- Technical indicator calculation engine.
- Historical market data analysis.
- Indicator-based trading signal generation.

### 🎯 Trading Signals

- BUY/SELL signal detection.
- Rule-based quantitative trading strategies.
- Signal filtering and analysis.

### 💰 Money Flow Analytics

- Market money flow monitoring.
- Foreign investor trading analysis.
- Sector rotation analysis.
- Market breadth indicators.

### 🖥️ Interactive Dashboard

- Built with Streamlit.
- Technical chart visualization.
- Trading signal exploration.
- Market data analysis.

## 🛠️ Technology Stack

- **Language:** Python
- **Database:** PostgreSQL
- **Dashboard:** Streamlit
- **Data Source:** SSI Market Data API (original provider)
- **Architecture:** Data Pipeline, Indicator Engine, Signal Detection Engine
